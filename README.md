## 目录结构约定

```
/
├── LICENSE          # 根许可证（MIT），仅覆盖本人原创/整理部分
├── NOTICE           # 第三方组件致谢与许可证指向（合规必备）
├── README.md        # 本文件
├── .gitignore       # Python
└── <项目名>/         # 每个子项目一个目录，自带其原有 LICENSE/NOTICE
    ├── README.md
    ├── src/
    └── vendor/       # 第三方二进制/许可证（保留原 LICENSE 文本）
```

## 合规原则（发布前自查）

1. 只收录**可再分发**的开源（拒绝无许可证 / 专有商业软件）；
2. copyleft 组件（GPL/LGPL/AGPL）必须保留其许可证与源码获取链接；
3. 必须保留原作者署名，不声称原创、不售卖软件本身；
4. 发布前过一遍密钥/敏感文件扫描。
